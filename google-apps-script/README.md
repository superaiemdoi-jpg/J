# 🍽️ คู่มือการเชื่อมต่อ Google Sheets & Google Apps Script เข้ากับระบบ POS ร้านอาหาร

ระบบนี้ถูกออกแบบให้คุณสามารถใช้ **Google Sheets เป็นฐานข้อมูลบนคลาวด์ (Cloud Database)** ได้ฟรี 100% โดยไม่ต้องเช่าเซิร์ฟเวอร์ฐานข้อมูลภายนอก ข้อมูลออเดอร์, คลังวัตถุดิบ, เมนูอาหาร, และรายจ่ายจะถูกบันทึกลงสเปรดชีตของคุณโดยตรงแบบเรียลไทม์

---

## 🚀 ขั้นตอนการติดตั้ง (ใช้เวลาเพียง 2 นาที)

### ขั้นตอนที่ 1: สร้าง Google Sheet เปล่า
1. เข้าไปที่ [sheets.new](https://sheets.new) หรือเปิด Google Drive แล้วสร้าง **Google ชีตใหม่**
2. ตั้งชื่อไฟล์ตามต้องการ เช่น `POS Database - ครัวไทยรสเอก`

---

### ขั้นตอนที่ 2: เปิด Apps Script
1. ที่เมนูด้านบนของ Google Sheet ให้คลิกที่ **ส่วนขยาย (Extensions)** > **Apps Script**
2. จะเปิดหน้าต่างโค้ด Apps Script ขึ้นมา

---

### ขั้นตอนที่ 3: วางโค้ด `Code.gs`
1. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกทั้งหมด
2. คัดลอกโค้ดทั้งหมดจากไฟล์ `google-apps-script/Code.gs` มาวางในหน้านี้
3. กดปุ่ม **บันทึก (Save)** (ไอคอนแผ่นดิสก์ หรือกด Ctrl + S / Cmd + S)

---

### ขั้นตอนที่ 4: สร้างตารางและหัวข้ออัตโนมัติ (ครั้งแรกเท่านั้น)
1. ในแถบเครื่องมือด้านบน จะมีดรอปดาวน์เลือกฟังก์ชัน ให้เลือกฟังก์ชัน **`initDatabase`**
2. กดปุ่ม **▶ เรียกใช้ (Run)**
3. Google จะขอให้คุณ **ให้สิทธิ์การเข้าถึง (Review Permissions)**:
   - กดปุ่ม "ตรวจสอบสิทธิ์" (Review permissions)
   - เลือกบัญชี Google ของคุณ
   - กด "ขั้นสูง" (Advanced) ด้านล่างซ้าย
   - กด "ไปที่ ... (ไม่ปลอดภัย)" (Go to ... (unsafe))
   - กด **"อนุญาต" (Allow)**
4. เมื่อฟังก์ชันทำงานเสร็จ ให้กลับไปดูที่ Google Sheet คุณจะเห็นแท็บตารางทั้งหมดถูกสร้างขึ้นมาอย่างสวยงาม:
   - 📊 **Dashboard** (หน้าสรุปภาพรวม ยอดขาย กำไรขั้นต้น และสินค้าคงคลัง)
   - 🛒 **Orders** (ตารางออเดอร์คำสั่งซื้อ)
   - 🍲 **OrderItems** (ตารางรายการอาหารแต่ละจานและท็อปปิ้ง)
   - 📖 **MenuItems** (ตารางเมนูอาหาร ราคา ต้นทุน และสูตร)
   - 📦 **Inventory** (ตารางคลังวัตถุดิบ ระดับสต็อก และเกณฑ์แจ้งเตือน)
   - 🧾 **Expenses** (ตารางบันทึกรายจ่ายและใบเสร็จสแกน)
   - 👥 **Users** (ตารางพนักงานและรหัส PIN)
   - ⚙️ **Settings** (การตั้งค่าร้าน)

---

### ขั้นตอนที่ 5: นำไปใช้งานเป็นเว็บแอป (Deploy as Web App)
1. คลิกที่ปุ่มสีน้ำเงินมุมขวาบน: **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. คลิกที่รูปฟันเฟือง ⚙️ ด้านซ้าย เลือก **เว็บแอป (Web app)**
3. กำหนดค่าดังนี้ (**สำคัญมาก!**):
   - **คำอธิบาย (Description)**: `POS API v1`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (your-email@gmail.com)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access)**: **`ทุกคน (Anyone)`** *(ต้องเลือกข้อนี้เพื่อให้แอป POS ส่งข้อมูลเข้าได้)*
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
   *(ตัวอย่าง: `https://script.google.com/macros/s/AKfycbx.../exec`)*

---

### ขั้นตอนที่ 6: เชื่อมต่อในระบบ POS
1. เปิดหน้าเว็บระบบ POS
2. คลิกที่ปุ่ม **Google Sheets** ที่แถบด้านบน
3. วาง URL เว็บแอปที่คัดลอกมาลงในช่อง **"URL เว็บแอป Google Apps Script"**
4. กดปุ่ม **"⚡ ทดสอบการเชื่อมต่อ"**
5. กดปุ่ม **"⬆️ ซิงค์ข้อมูลทั้งหมดขึ้น Google Sheets"**
6. เปิดตัวเลือก **"ซิงค์อัตโนมัติ (Auto-Sync)"** เมื่อมีออเดอร์ใหม่ หรือเติมสต็อก ข้อมูลจะถูกบันทึกลงชีตทันที!

---

## 📡 รายละเอียด API Endpoints

### 1. HTTP GET:
- `GET ?action=ping` : ตรวจสอบสถานะการเชื่อมต่อ
- `GET ?action=getAll` : ดึงข้อมูลทั้งหมดในชีตมาแสดงใน POS
- `GET ?action=getOrders` : ดึงเฉพาะรายการคำสั่งซื้อ
- `GET ?action=getInventory` : ดึงเฉพาะข้อมูลคลังสินค้า

### 2. HTTP POST:
- `POST { action: 'createOrder', data: order }` : บันทึกออเดอร์ใหม่ พร้อมตัดสต็อก
- `POST { action: 'updateOrderStatus', data: { orderId, status, ... } }` : อัปเดตสถานะบิล
- `POST { action: 'addIngredient', data: ingredient }` : เพิ่มวัตถุดิบใหม่
- `POST { action: 'updateIngredient', data: ingredient }` : แก้ไขสต็อกวัตถุดิบ
- `POST { action: 'deleteIngredient', data: { id } }` : ลบวัตถุดิบ
- `POST { action: 'addExpense', data: expense }` : บันทึกค่าใช้จ่าย
- `POST { action: 'syncAll', data: { orders, menu, inventory, ... } }` : อัปโหลดข้อมูลทั้งหมด
